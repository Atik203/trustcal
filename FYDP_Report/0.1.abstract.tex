	{\huge \bf Abstract}
	\line(1,0){430}
\end{center}

%The abstract should contain a summary of the work presented in the report in a single paragraph. The paragraph should provide a general background of the problem, methodology and results.

Large language models can answer scientific questions fluently, and multi-agent debate can improve their reliability, but a confident wrong majority can pressure a correct minority agent into abandoning the correct answer. We call this failure sycophantic collapse; its terminal state is sycophantic consensus. Existing mitigations refine prompts, weight agents by self-reported uncertainty, or verify claims with retrieval and tools; none ties an agent's influence to claim-level external evidence during the debate. This report asks whether evidence-grounded trust reduces sycophantic collapse relative to a matched majority-vote control, and where verifier accuracy and evidence redundancy place its boundary. The framework runs three heterogeneous agents for three rounds, decomposes each response into atomic claims, routes each claim to a domain-specific source pair, assigns supported, contradicted, or unverifiable verdicts through a verifier interface, and updates a bounded trust vector through logit accumulation, one softmax, and a simplex projection; the final answer is a trust-weighted plurality. The evaluation is a pre-registered 24-run Core matrix on GPQA-Main and MMLU-Pro (primary), with HLE as a ceiling control, and a 32-row Full target with the gold-evidence oracle on SciClaimBench (36 rows with the gold-answer oracle as an alternate) that adds placebo and oracle controls. External evidence is independent of an agent's self-reported confidence; B8-no-trust removes the trust signal and the trust-weighted aggregation together, and B4-matched isolates the evidence channel; two seeds, paired question-level analysis, and a pre-registered 5-point non-inferiority/7.5-point minimum detectable difference make the comparison falsifiable. The current evidence is engineering and one completed Core row: the 13-check P0 gate passes 13/13, the suite contains 615 tests (514 at the P0 release), Gate 0 completed 10/10 vanilla debates with 90/90 non-empty positions at a mean of 370.8 seconds, and the first Core row finished 798 debates on 399 eligible GPQA-Main questions (seed 1, 4-bit stack, three rounds, temperature 0.7). The trust arm (B8) reaches 0.624 accuracy (249/399, 95\% CI 0.58--0.67) against 0.586 for the matched majority control (234/399, CI 0.54--0.63). The paired difference (+0.038, exact McNemar $p=0.086$) is not significant, minority retention is 0.78 versus 0.75, and trust calibration is uninformative (AUROC 0.52, Brier 0.29), so the row reads as feasibility and timing evidence --- mean 138 seconds per pair, about 15.3 GPU-hours --- not an efficacy claim. The remaining Core rows, the placebo/oracle Full controls, and the second seed are outstanding.

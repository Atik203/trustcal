\textbf{Reading the figure.} Thin lines are cumulative accuracy after each question; markers are milestone snapshots with 95\% CIs. MPR, CCR-e and pair time are milestone-only because they are defined per snapshot, not per question.

\textbf{What this does not show.} One dataset, one seed, 201 questions; the pressure arms are not in this row, so the CMR and CCR-e denominators are sparse; the accuracy difference is not significant at this $n$ (exact McNemar $p=0.099$); these are feasibility and timing results, not an efficacy claim.
